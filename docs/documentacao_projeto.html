1. Visão Geral do Circuito

Este projeto implementa dois sistemas de modulação digital em VHDL: NRZ-L (Non-Return-to-Zero Level) e NRZ-I (Non-Return-to-Zero Inverted). Ambos os sistemas convertem uma sequência de 16 bits de entrada em um sinal serial modulado com temporização precisa.

NRZ-L (Unipolar Non-Return-to-Zero Level)

O módulo nrz_l implementa a codificação NRZ-L, onde a representação do bit é feita pelo nível do pulso mantido durante todo o intervalo do bit:

  • Bit '1': Linha em nível ALTO durante todo o período do bit
  • Bit '0': Linha em nível BAIXO durante todo o período do bit

O módulo recebe um vetor de 16 bits pela porta data_in e gera, na saída nrz_out, um sinal modulado em NRZ-L. A duração de cada bit é definida pelo generic TICKS_PER_BIT, que controla um contador interno responsável por determinar o instante de troca de bit.

NRZ-I (Unipolar Non-Return-to-Zero Inverted)

O módulo nrz_i implementa a codificação NRZ-I, onde a representação é feita pela transição da linha, não pelo nível absoluto:

  • Bit '1': Provoca uma alternância (toggle) da linha em relação ao estado anterior
  • Bit '0': Mantém o estado anterior da linha

Este esquema é superior para recuperação de clock, pois garante transições mesmo em sequências de zeros. O módulo utiliza o sinal interno current_lvl para armazenar o estado anterior da linha e implementar a lógica de transição.

4. Parâmetros (Generics)

Ambos os módulos aceitam dois parâmetros genéricos que controlam seu comportamento:

Generic Tipo Função
DATA_WIDTH integer Largura do barramento de dados (padrão: 16 bits). Define quantos bits são transmitidos em sequência.
TICKS_PER_BIT integer Número de ciclos de clock por bit de dados. Padrão: 100000000 (NRZ-L), 10 (NRZ-I). Controla a taxa de transmissão dos dados.

Exemplo de uso em VHDL

-- Instanciação com parâmetros padrão nrz_l_inst : entity work.nrz_l port map ( clk => clk_100mhz, reset => btn_reset, data_in => sw_16bit, nrz_out => led_modulated ); -- Instanciação com parâmetros customizados nrz_i_custom : entity work.nrz_i generic map ( DATA_WIDTH => 32, TICKS_PER_BIT => 20 ) port map ( clk => clk, reset => reset, data_in => data(31 downto 0), nrz_out => output );

Cálculo da Taxa de Dados

A taxa de dados (baud rate) pode ser calculada como:

Taxa de dados = f_clk / TICKS_PER_BIT

Exemplo: Com f_clk = 100 MHz e TICKS_PER_BIT = 100000000, a taxa é 1 bit/segundo.

5. Funcionamento Interno

Mecanismo de Temporização

Ambos os módulos utilizam um contador interno tick_counter que controla o tempo de transmissão de cada bit:

  1. Inicialmente, tick_counter = 0
  2. A cada ciclo de clock, o contador é incrementado
  3. Quando atinge TICKS_PER_BIT - 1, o contador reseta e um novo bit é selecionado
  4. O tempo total de cada bit = TICKS_PER_BIT ciclos de clock

Seleção Sequencial de Bits

O módulo bit_ptr funciona como um índice que aponta qual bit está sendo transmitido:

  • Começa em DATA_WIDTH - 1 (bit mais significativo)
  • Decrementa a cada período de TICKS_PER_BIT
  • Quando atinge 0, volta para DATA_WIDTH - 1 (comportamento cíclico)

A saída bit_idx expõe este índice para fins de debug em simulação.

Lógica NRZ-L

A lógica de saída do NRZ-L é simples:

-- Continuamente transmitir o bit apontado por bit_ptr nrz_out <= data_in(bit_ptr);

O sinal de saída reflete diretamente o valor do bit sendo transmitido, mantendo seu nível durante todo o intervalo TICKS_PER_BIT.

Lógica NRZ-I

A lógica de NRZ-I é mais complexa, pois implementa a regra de transição:

if tick_counter = 0 then -- Início de um novo bit if data_in(bit_ptr) = '1' then -- Bit '1': alternar a linha current_lvl <= not current_lvl; nrz_out <= not current_lvl; else -- Bit '0': manter o estado anterior nrz_out <= current_lvl; end if; else -- Manter a linha estável durante o resto do período nrz_out <= current_lvl; end if;

Consequências da lógica NRZ-I:

  • Uma sequência de '1's alterna a linha: 0, 1, 0, 1, 0, 1, ...
  • Uma sequência de '0's mantém a linha constante: 1, 1, 1, 1, 1, ...
  • Garante transições frequentes mesmo em dados com muitos zeros
  • Facilita a sincronização de clock no receptor

Reset Assíncrono

Quando reset = '1', ambos os módulos retornam aos estados iniciais:

  • bit_ptr ← DATA_WIDTH - 1
  • tick_counter ← 0
  • nrz_out ← '0'
  • current_lvl ← '0' (apenas NRZ-I)

Operação da Placa

  1. Configurar entrada: Use os 16 switches para definir o padrão de bits a ser transmitido
  2. Observar saída: O LED 0 (mais à direita) mostra o sinal modulado em tempo real
  3. Monitorar índice: Os LEDs 12-15 (mais à esquerda) mostram em binário qual bit está sendo transmitido
  4. Reset: Pressione o botão central para retornar ao primeiro bit (MSB)
  5. Osciloscópio (NRZ-L): Conecte o osciloscópio ao Pmod JA1 para visualizar o sinal sem delays

8. Exemplos de Uso

Simulação em VHDL

Para simular o comportamento do módulo:

  1. Abra o Vivado
  2. Carregue o projeto: Projeto NRZ-L.xpr ou Projeto NRZ-I.xpr
  3. Clique em Run Simulation → Run Behavioral Simulation
  4. Observe os sinais no waveform viewer

Síntese e Programação

  1. Executar síntese: Run Synthesis
  2. Executar place and route: Run Implementation
  3. Gerar bitstream: Generate Bitstream
  4. Programar a placa via Program Device

Verificação Funcional

Para verificar o funcionamento correto na placa:

  1. Configure os switches para um padrão conhecido (ex: alternado: 0x5555)
  2. Observe o LED 0 pulsando conforme esperado
  3. Verifique os LEDs 12-15 contando de cima para baixo (binário)
  4. Utilize o botão reset para retornar ao MSB

9. Observações Técnicas

Timing

O módulo é síncrono ao clock de 100 MHz. Todas as operações ocorrem nas bordas de subida do clock (rising_edge(clk)). O reset é assíncrono.

Sincronismo de Dados

A saída nrz_out pode ser observada simultaneamente com bit_idx para verificar qual bit está sendo transmitido. Esta correspondência é útil para debug em simulação.

Comportamento Cíclico

Após transmitir todos os 16 bits, o módulo automaticamente retorna ao primeiro bit (MSB) e inicia uma nova transmissão. Este padrão repete indefinidamente até um reset.

Extensibilidade

Os generics DATA_WIDTH e TICKS_PER_BIT podem ser modificados para criar instâncias customizadas:

  • Aumentar DATA_WIDTH para transmitir mais bits
  • Reduzir TICKS_PER_BIT para aumentar a taxa de transmissão
  • Ajustar a taxa para compatibilidade com receptores específicos

💡 Dica: Para visualizar melhor o comportamento da modulação, ajuste TICKS_PER_BIT para um valor pequeno (ex: 10-100) durante simulações. Na prática, valores maiores são usados para simular taxas de transmissão realistas.
